## 资源与数据边界

- 翻译最多 512 段 / 512 KiB，8 段一批；300 ms MutationObserver 去抖，达到限额停止观察。
- 选文 16 KiB，页面附件 64 KiB；插入/替换显式分开，撰写要求和附加上下文用于重试。
- 视频只读来源十分钟失效，绑定 native document / 视频 / 分 P / 轨道 / media source；
  不接触 VideoDubbingController 私有连接、缓存，不注入配音播放器。
- 视频问题附加最多 54 KiB 带时间字幕，截断有明确提示；字幕源授权与配音设置独立。
- 剪藏最多 500 条、4 MiB，总条目 64 KiB，保留用户保存的完整来源 URL。
- 截图先检查当前可见网页，再隐藏自有 UI、真实采集/裁剪、复核来源，预览后才发送。
  截图最大 8 MiB / 4096²；token 三分钟有效；最多四份图像、两个在途识图请求，90 秒超时。
- 识图配置只在打包设置页读写，凭据默认 session，显式 remember 才本地保留；图像和回答不写历史。
- Quick Ask / 视频文本请求遵循原 Assistant 的历史开关；停止、关闭、切页、导航和撤权清理所有权。

## 测试环境与证据范围

首次 E2E 超时是共享 `extension/` 被另一轮验证构建为 Firefox。检查 manifest 后安全重建
Chromium，未删除其他会话的发布包。最终构建保留 `extension.*`，只重建展开目录。

生产 E2E 使用本机 HTTP/JSON/SSE、原生 video/VTT、SVG 图片及一次性 Chromium profile。
截图专用测试将生产 JS 复制到临时目录，仅给该副本声明 `<all_urls>` 以运行真实浏览器采集；
headless 无法点击原生工具栏赋予 activeTab。正式 manifest 不增加全站截图权限；普通 profile
另行检查拒绝截图时可见的工具栏激活提示。测试核对 PNG 160×100、背景像素 RGBA
`[181,44,40,255]`，并确认预览前没有任何模型请求，之后才出现 image_url。

已验证的编辑器为原生 textarea/text input 与普通 contenteditable；不声称已验收 Gmail、Notion
或任意富文本框架。真实 YouTube/Bilibili 登录轨道、收费模型质量、真实工具栏临时授权及 Firefox
新任务 UI 仍需分别实机验收。原 Monica 参考仍为本机 9.0.24 静态包与官方指南，未声称完成其在线 UI 对照。
