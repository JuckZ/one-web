## 已实现的功能切片

- 普通选文新增语法检查、精简、扩写、正式语气和回答选文问题；编辑器保留撰写与回复。
- 更多菜单展示完整可用动作，直接固定或取消固定，最多四项；鼠标专用手柄、键盘上移/下移均可排序。
- 排序移动原 DOM 节点，保留焦点、可读顺序和编辑器原选区；可 Escape 取消拖动，列表可自动滚动。
- 就地选择八种常用输出语言，实际模型和模板使用该设置；重试保留原请求语言。
- 选文条增加显式关闭；关闭后保持收起，新的选文手势或 Alt+Shift+T 可重新显示。
- 右侧网页阅读展开总结当前页、附加当前页的问答及阅读设置；Alt+Shift+S 在已启用网页中触发总结。
- 可固定右侧工具栏，重载恢复；窄屏中对结果面板预留空间，选文工具条与侧栏发生冲突时临时切换显示。
- 添加快捷动作直接进入自定义工具表单，保存后可执行真实页面请求，沿用既有权限和动作管理。
- 关闭生成中的结果会中止真实 HTTP 流；旧响应按 generation 失效，新请求等待旧 start/cancel 结束，避免旧取消落到新请求上。

这轮没有新权限、服务凭据、外传 origin 或脚本执行接口。用户内容仍按参考资料处理，写回仍需明确点击并复核原节点与选区。
新增本地固定 ID、语言与侧栏布尔偏好已记录在 [隐私清单](../privacy-data-inventory.md)。
