# Dubbing 截图能力与 OneWeb 迁移进度核查

日期：2026-11-15。用途：回答用户提供的五张 Dubbing V4.6.1 截图中的能力是否应迁移，以及当前完成度。
这是范围与进度核查，没有扩大实现规格、修改运行代码或重新发布插件。

## 结论与核查口径

已交付的是“当前网页视频 → 获取或导入字幕 → 翻译 → TTS → 同步播放与清理”的核心链路。
截图中的高级控制和离线媒体工作台没有全部迁移。此前规格明确将本地视频库、
独立 MP3/MP4 导出、人声分离及声纹克隆排除于首轮范围；“未实现”与“应在外部承载”分别记录。

按根 AGENTS.md 的产品定位，直接改善当前网页观看体验的功能优先进入插件；
通用媒体生成、文件库管理、编辑和复杂导出由独立网页、桌面软件或外部服务承载。
截图只能证明入口和文字声明，不能证明参考插件的后台算法、声音供给或完整导出已通过验收。
最初研究基线为 4.5.14；本轮未对参考插件 4.6.1 安装包进行新的源码级审查。

## 建议的后续次序

1. 关闭现有核心链路的听评与连续播放验收缺口，遇到缺陷继续按既定 T1～T4 先复现再修复。
2. 补齐字幕字号、字幕显示/目标语言/音量偏好保存，以及声音选择与试听。
3. 增加命名服务配置、明确的手动切换及轻量配音入口；避免把兼容接口误写成某个供应商已接入。
4. 再单独定义多说话人的手动角色映射；自动说话人识别与背景音分离由外部服务承担计算。
5. 为离线文本/字幕/视频制作设计独立工作台及 OneWeb 发起/结果返回流程。已有 LAN 翻译/TTS 可作为基础，但完整离线导出工作流仍需另行实现与验收。

以上为建议顺序，不把未实现项写作已批准、已交付或承诺完成日期。
