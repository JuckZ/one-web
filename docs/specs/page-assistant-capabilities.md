日期：2026-11-15。用户在确认上一轮重载后提供两张参考截图，要求继续开发缺失的界面功能。
本轮按浏览器任务补齐能力，沿用已批准的 T1/T2/T3/T4 公开边界及既有权限、模型服务与编辑器写回契约。

## 浏览器场景与边界

选文处理依赖当前页面或编辑器的真实选区，在附近完成选择动作、配置和预览，减少复制到外部应用。
网页阅读依赖当前授权页面的正文，提供总结、问答和返回原页；计算继续使用用户配置的模型。
本轮不创建媒体生成或独立知识库工作台。参考图片中没有文字说明的图标，不凭形状声称已实现其完整服务。

## 数据与生命周期

`PageToolsController` 继续拥有有界动作及偏好。工具条增加可选固定动作 ID 和语言，旧配置缺失时保留原有前四项行为。
新增偏好只保存本机动作 ID、语言与工具栏显示选择，不保存额外页面正文或凭据。
只允许有限页面协议命令；配置保存前校验类型、数量与语言格式，内容页无法读模型密钥。

菜单排序移动已有节点，保持焦点、DOM 顺序与视觉顺序一致。拖动只从专用手柄开始，可 Escape 取消，有可发现的键盘移动控制。
新增监听、计时器和异步工作有清理或失效判断；页面变化后不恢复旧任务面板或写回旧选区。
