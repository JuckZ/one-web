# OneWeb 页面工具双目标与旧项目收敛

日期：2026-11-17。用户明确要求审计 OneTampermonkey 整合情况、重写通用功能、从 OneWeb 构建独立油猴脚本，验收后删除旧本地项目及 GitHub 仓库。

## 产品与承载

在浏览页面时显示密码、编辑本页、解除复制限制、查看已加载隐藏元素、测量间距、舒适阅读和搜索选文，都依赖当前页面。OneWeb 是唯一维护仓库；扩展与 userscript 直接共用有限的 Page Toolbox catalog、校验、生命周期和 DOM 实现。油猴仅新增 GM 菜单/存储和启动适配，不模拟 browser API、不调用扩展后台，也不把其他扩展模块强行打入脚本。

## 旧功能处置

九菜单的通用价值由七工具与管理入口接管。旧版私网报表/注释表格还原、Cookie访问绕过、自动同意协议/业务点击重放、analytics 全局置空、第三方下载后 eval、未调用的商店重定向和 Vue demo 明确淘汰。新功能独立重写；“全部收敛”不表示复刻这些私有或无效实现。

旧脚本身份是 `OneMonkey` / `npm/vite-plugin-monkey`，GM 存储按身份隔离。新脚本为 OneWeb，不能自动读取旧 GM 状态；用户需重新按站点启用。安装新版前停用旧 OneMonkey，避免两套脚本同时改页面。

## 验证与边界

核心检查沿用 factory 类型/lint/全单测。新工具必须验证所有权、清理、设置拒绝和无自动外传；用户脚本验证发货文件、真实 DOM、站点隔离、保存失败/迟到写入、菜单与 BFCache。真实 Tampermonkey 安装单独记录，GM边界替身不能替代管理器证据。扩展执行生产 Chromium 工具箱回归；Firefox 构建/严格manifest与真实临时安装工具箱路径单列。实际命令/最终证据在同名 task result，历史通过数不作为本轮证据。

油猴不提供原生侧边栏、书签/Cookie/WebRTC设置等扩展权限；本次页面工具无 LLM 调用。新链接搜索属于显式 searchTerms 外传，Firefox 声明与隐私清单同步更新。不会自动安装到用户现有浏览器、发布脚本或推送源码。
