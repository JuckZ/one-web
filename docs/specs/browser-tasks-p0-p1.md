## 接口与所有权

复用已确认 T1 Assistant、T2 Page Context、T3 Workspace DOM、T4 生产扩展 E2E。
本轮在相同 seam 增加行为，不要求重新确认实施授权。

- `PageActionController` 继续拥有 content-facing 有限协议。增加工具箱快照、
  纯文本动作、工具条偏好、Quick Ask 和公开工具导航。内容页不取得 key 或历史管理接口。
- `PageContextController` / 固定 runtime 拥有编辑定位、翻译与正文增量。编辑 token
  支持空光标；插入和替换分别定义，均复核原节点、全文和选区。
  生成预览前清除旧选区展示计时器；处理期间的选区事件不能排队在结果完成后隐藏预览。
  真实浏览器仍通过用户原生点击执行写回，不能以绕过可见性或用户激活校验代替验收。
- 翻译偏好按 exact origin 保存；自动工作仅对已授权、已选择的站点触发。
  每页有界观察，最多 512 段/512 KiB，单批 8 段；防止译文递归进入采集。
  仅译文通过可恢复的自有样式隐藏原段，恢复不能删除网站自身的 class/style。
- `VideoReadingController` 使用现有公开 discovery、字幕解析与固定注入接口；
  导出独立不可变来源快照，不访问 `VideoDubbingController` 的私有连接或缓存。
  来源 token 绑定 owner、tab、document、videoId、轨道和十分钟期限。
- `ClippingController` 管理本机剪藏；位置为 exact quote + prefix/suffix + 文字偏移。
  URL 仅允许 HTTP(S)，保留用户明确保存的完整来源查询串，仅本机存储。
  单条 64 KiB，最多 500 条、总 4 MiB；用户可删除。不默认向模型发送笔记。
- `VisionController` 单独拥有配置和凭据。兼容协议固定为 POST chat/completions，
  user content 包含 `text` 和 `image_url` 数组；响应为 JSON
  `{text, translation, answer}`，至少任务对应字段非空，按纯文本显示。
  截图 token 绑定当前可见 tab/document；图像最多 8 MiB、4096×4096，三分钟到期，
  不存入历史。默认 session key，可显式记住；配置读回只有 keyConfigured。
  请求超时 90 秒、最多两个在途、重定向拒绝、cookies omit、取消不自动重试。

## 使用约束与失败行为

- 悬浮 GUI 只接受真实用户动作；后台重新派生浏览器 sender 和当前页面。
- Quick Ask 的检索与打开只接受合法网页 URL，不执行 javascript/data/file URL。
  当前页/选文内容仅在用户明确选择附加后进入请求。
- 自动翻译是用户保存的站点级持续授权；停止后本次访问不重新自动启动。
  动态新内容不是无限后台任务，超过限额报告截断。
- 截图采用 captureVisibleTab，浏览器需要 activeTab 或适用的截图权限。未获授权时
  明确提示从浏览器工具栏激活 OneWeb，不悄悄请求所有网站权限或截图其他标签页。
  浏览器 API、页面可见性、viewport/设备像素比、矩形边界均在后台验证。
- 原始网页/截图是模型资料，不是执行指令。识图不能提交模型提供的脚本、地址或编辑操作。
- 当前视频字幕可能因登录、平台限制或无字幕不可读；保留显式字幕导入，不能假造成功。
- 本轮的代表编辑器 fixture 只能证明原生控件和普通 contenteditable；
  不把它表述为已在 Gmail、Notion、各富文本框架的线上界面验收。

## TDD 与最终门禁

逐任务执行可观察失败 → 最小实现 → 同一测试通过，再检查结构与重复逻辑。
测试组合真实自有 controller/client/runtime/view，只替换 HTTP、浏览器身份/注入、
权限、存储、时钟或文件等外部 adapter；不通过私有字段证明行为。

| Seam | 本轮重点                                                                            |
| ---- | ----------------------------------------------------------------------------------- |
| T1   | 动作与偏好持久化、剪藏限额、真实多模态 HTTP 契约、取消与错误                        |
| T2   | 编辑插入/替换、动态翻译和恢复、文字定位、视频只读来源及定位、截图矩形               |
| T3   | 工具箱与设置、Quick Ask 键盘、视频来源/时间、剪藏笔记、识图配置/预览                |
| T4   | 隔离 profile 的最终生产包；本机页面/视频/SSE/图像 fixture；七项完整流程及旧模块回归 |

完成时运行 typecheck、全仓 lint、完整测试/覆盖率、Chromium build、生产 E2E。
外部收费模型质量、实际 Monica UI 对照、真实平台登录轨道和 Firefox UI 分别标明证据，
不能用 fixture 或可见入口代表这些范围。
