# 网页助手浮层与交互修复

日期：2026-11-15。用户在实际 GitHub 页面截图指出，OneWeb 的绿色大按钮工具条和长菜单与参考产品存在明显交互差距。
本轮改善当前网页的选文操作和常用任务入口；沿用已批准的 T3/T4 DOM 与生产扩展边界。
既有翻译、写作、Quick Ask、视频阅读、剪藏、识图、工具箱流程和权限保持原契约。

| 编号  | 可观察验收                                                                                        |
| ----- | ------------------------------------------------------------------------------------------------- |
| PS-01 | 选文工具条为单行紧凑图标按钮，具有可读名称和提示；320px 宽视口也不越界，不遮住所选文字。          |
| PS-02 | 右侧入口以图标栏呈现六项常用网页任务；隐藏/关闭等次要操作按需展开，默认不出现长文本菜单。         |
| PS-03 | 选文工具条、入口菜单与任务面板互斥展开；外点和 Escape 关闭短暂浮层，滚动/缩放后不遗留悬空工具条。 |
| PS-04 | 可用动作仍遵守排序/隐藏偏好；超出紧凑工具条的动作通过更多入口执行，编辑器选区与显式写回不丢失。   |
| PS-05 | 图标工具条支持键盘进入、方向键和 Home/End；关闭后焦点有明确归属，Tab 不被困住。                   |
| PS-06 | 明暗主题、窄屏、真实翻译/写作及七项网页任务回归通过；不把视觉改造等同新增未实现的参考产品能力。   |

原生 Popover 承担短暂浮层与外点关闭；工具条语义与键盘导航优先原生 focusgroup，缺失时使用有限回退。
选区定位根据实际渲染尺寸夹在视口内；更多面板在支持 CSS anchor 时采用原生锚定，否则测量触发器定位。
截图证据使用生产包与本机确定页面/服务，不读取原插件凭据或注入其实现。

编辑器原选区恢复产生的延迟 `selectionchange`，若节点、起止位置和原文都未变，应保留已完成预览和显式写回按钮。真正更换选区或编辑原文时，仍刷新选文操作；后台写回继续复核原文与选区，不由重复事件触发。
