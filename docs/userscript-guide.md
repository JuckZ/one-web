# OneWeb 油猴脚本：安装与使用

OneWeb 的轻量脚本提供七项页面工具，不需要 OneWeb 扩展、本地服务、账号或 LLM API。
完整侧栏、RepoLens、书签、Cookie 和网络策略等功能请使用浏览器扩展。

> **实验项目**：当前发布用于功能验证与个人试用，功能和数据结构可能调整。
> 当前可用版本以 [GitHub Releases](https://github.com/JuckZ/one-web/releases/latest) 为准，构建与发布进度见 [Actions](https://github.com/JuckZ/one-web/actions)。

## 正式安装

1. 从 [Tampermonkey 官网](https://www.tampermonkey.net/)进入浏览器商店，安装 Tampermonkey。
   本轮实测为 Linux、Chromium 153、Tampermonkey 5.5.1；其他管理器和平台尚未实测。
2. Chrome 如显示“请启用用户脚本”，在 `chrome://extensions` → Tampermonkey → 详情中开启
   **允许用户脚本**，并按当前管理器提示启用所需的开发者模式。仅开启 Tampermonkey 的权限。
3. 点击 [安装 OneWeb 稳定版](https://github.com/JuckZ/one-web/releases/latest/download/one-web.user.js)。
   Tampermonkey 应打开安装确认页；核对名称 **OneWeb**、作者 **Juck**、namespace 为
   `https://github.com/JuckZ/one-web`，然后点击 **安装**。
   `.meta.js` 是更新检查文件，不是安装入口。
4. 若原来装过 OneMonkey，先在管理器中停用它并刷新网页，避免同时改动页面。
   OneWeb 不读取旧脚本的设置。
5. 打开普通 HTTP(S) 网页并刷新。点击油猴图标，在 OneWeb 菜单中选择
   **OneWeb · 启用当前站点工具**，再从浮动入口打开面板并逐项启用工具。
   未批准的网站保持关闭；协议、域名和端口不同分别设置。

若点击后直接下载文件，可用下述本地安装方法；不要安装 GitHub 仓库源码、ZIP、`.meta.js` 或源码页 HTML。

## 从本地文件安装

维护者运行 `pnpm build:userscript`，得到 `artifacts/build/userscript/one-web.user.js`。
普通用户使用维护者交付的同名文件即可，无需 Node 或构建环境。

在 Tampermonkey 中选择 **添加新脚本**，将编辑器内容全部替换成该文件全文，保存，再刷新目标网页。
如管理器提供“实用工具 → 从文件导入”，也可选取该文件后核对安装确认页。
本地安装文件也使用同一更新地址；无网络或下载失败时可继续使用已安装版本。

若管理器已有 OneWeb，优先选择已有记录的更新/覆盖确认，保留同一脚本的存储；不要删除旧记录再重装。
历史候选没有更新 URL 的，应从正式地址更新安装一次，确认仍只有一条 OneWeb，再检查更新设置。

## 七项工具

所有工具独立、默认关闭。在已启用的站点按需开启：

| 工具              | 使用方式与范围                                                                                                                   |
| ----------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 密码查看          | 启用后双击需要查看的密码框，再次双击切回隐藏；关闭工具恢复。注意周围的人与屏幕共享。                                             |
| 网页自由编辑      | 临时编辑页面文本；不修改服务器内容，刷新会丢失编辑。                                                                             |
| 解除选择/复制限制 | 解除有限的页面样式和事件限制；不保证所有网站兼容。                                                                               |
| 元素间距测量      | **Alt+单击**选择两个元素；或聚焦元素后按 **Alt+Shift+M**。显示尺寸、水平及垂直间距，Escape 清除。                                |
| 夜间阅读          | 脚本版开启固定轻度减光（12%），关闭即撤销；暂不提供强度选择，不是自动深色主题。                                                  |
| 隐藏内容          | 临时显示已加载的视觉元素；跳过表单、输入和编辑区域，不绕过登录、付费或服务端权限。使用自由编辑时，先暂停编辑，再重新启用本工具。 |
| 选文搜索          | 选中文字，预览 npm/GitHub 搜索链接，点击后才向所选网站发送选文。输入框内容不参与。                                               |

通过 OneWeb 菜单 **停用当前站点工具** 可立即停止并清理本页修改；
**忘记当前站点设置** 同时删除该站点保存的选择。刷新和重新打开页面会按已保存的设置启动。
扩展版与脚本版分别保存设置；如果同时安装，在同一网站只启用一套页面工具即可。

## 更新与回退

正式版本由 GitHub Releases 分发。管理器按自身设置定期读取 `one-web.meta.js`，发现更高版本再下载
`one-web.user.js`。检查频率、是否自动安装及权限变化确认由管理器决定，OneWeb 不自行联网下载代码。

- **立即检查**：打开 Tampermonkey 管理面板，找到 OneWeb，点击该脚本的 **检查更新**，核对版本。
  更新后刷新已打开的目标网页，原有站点批准与工具设置应保留。
- **更新失败**：保留当前安装，稍后重试；先检查 GitHub 网络连接、管理器更新开关与更新/下载 URL。
  不要删除脚本来解决下载错误。端点失败时应继续使用已安装版本。
- **手动更新**：重新打开正式安装链接，在管理器中确认更新同一 OneWeb，避免创建重复记录。
- **回退**：先在管理器中导出脚本及其存储备份，并暂停该脚本自动更新。
  从 [版本列表](https://github.com/JuckZ/one-web/releases)打开所需历史版本的 `one-web.user.js`，
  按管理器提示确认安装较低版本，保留同一脚本身份，再刷新网页。
  这里介绍的是手动恢复操作；跨存储结构的降级兼容需要对应版本单独验证，本轮没有承诺。
  管理器可能拦截降级，可在已有记录编辑器中替换为该历史文件全文并保存。
  固定版本文件中的自动更新地址仍指向 Latest，暂停更新才会保持旧版。

每次发布均附 `SHA256SUMS`；维护者或高级用户可下载整个 Release 后运行 `sha256sum -c SHA256SUMS`。
它检查下载完整性，不是独立签名。普通用户以官方仓库地址和管理器安装确认页为准。

## 排查与卸载

| 现象                          | 检查                                                                                           |
| ----------------------------- | ---------------------------------------------------------------------------------------------- |
| 无菜单或浮动入口              | 确认管理器和脚本均启用、允许用户脚本、网页已刷新；需要先在管理器菜单批准当前站点。             |
| 浏览器内部页/PDF/扩展商店无效 | 脚本仅运行于允许注入的顶层 HTTP(S) 文档；浏览器受限页面与跨域 iframe 不受支持。                |
| 隐私窗口无效                  | 需要浏览器允许管理器在隐私窗口运行，行为和存储策略由管理器决定，未在本轮实测。                 |
| 设置未保留或重复菜单          | 检查是否同时安装旧脚本、多个 OneWeb 或扩展版工具；先备份，再停用多余记录并刷新。               |
| 保存报错                      | 本页工具会停止；检查管理器存储是否正常，然后重新启用，不会显示虚假的保存成功。                 |
| 更新仍是旧版                  | 确认 Release 已发布、版本确实提高、更新 URL 正确，手动检查后刷新原网页。确认 GitHub 下载可达。 |

停用整个脚本：在管理器中关闭 OneWeb，再刷新原来打开的网页。
卸载：如需保留设置，先用管理器导出脚本和存储备份，再删除 OneWeb，并按管理器提示删除其存储。
删除脚本或关闭管理器后，已打开页面可能仍保留修改，刷新即可清除；OneWeb 自身的停用/忘记操作会即时清理。

站点设置只由脚本管理器保存在本机。页面工具没有模型调用或遥测；选文只有在主动点击搜索链接后发送。
GitHub 更新检查与脚本下载由管理器发起，会产生普通网络访问元数据，不附带页面内容或站点设置。
